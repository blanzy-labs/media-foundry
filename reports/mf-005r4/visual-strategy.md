# MF-005R4 Visual Strategy

MF-005R4 adopts **prefer constructing the visual over embedding the visual**. The configured priority is Godot procedural scene, Godot project asset, Blender asset, authentic source media, then external static media.

The R4 Turd Burglar candidates use no static media. A reusable `ScrappyWorldStage` persists from 1.0–13.9 seconds and composes a dirty tiled room, pipe/depth plane, swaying lamp and light cone, dust, toilet, primitive masked beetle, reacting sack, generated turd/sparkles, physical signs, and dimensional title. Fixture events drive camera push/reveal/bump/settle, character entry/approach/exit, turd highlight/grab, punch sign, and title assembly.

The intro and studio outro are the only primarily text-only full-frame states. Renderer selection is based on `visual_strategy.preference`; there is no subject-name branch.
